**# Movie Recommendation System**

---

\- \*\*Language:\*\* Python 3.10

\- \*\*Database:\*\* MySQL 8.0 (Dockerized)

\- \*\*ETL (Level 1):\*\* Pandas \& SQLAlchemy

\- \*\*ETL (Level 2):\*\* Apache Spark (PySpark)

\- \*\*Infrastructure:\*\* Docker (Manual Management)
